# Product

## Platform

web

## Stack

Static HTML/CSS/vanilla JS, hébergé sur GitHub Pages (domaine djidonou.com). Pas de framework, pas de build step. Confirmé par l'utilisateur comme contrainte à préserver.

## Users

Public principal : recruteurs et employeurs qui cherchent le nom "Ulrich Djidonou" et évaluent en quelques minutes le sérieux du profil. Publics secondaires (non confirmés comme cibles de design) : pairs économistes, décideurs publics québécois, lecteurs de la veille La Frontière.

## Product Purpose

Site personnel d'Ulrich Djidonou, économiste quantitatif à Québec. Sert de preuve de compétence publique : projets démontrables, parcours, recherche, veille automatisée La Frontière. Succès sur 12 mois : crédibilité passive. Quand on cherche son nom, on trouve un profil sérieux et sobre. Pas d'objectif de trafic ni de génération de contacts.

## Positioning

Économiste quantitatif qui montre son travail réel plutôt que de le décrire : dashboards publics (ICIE), pipeline de veille automatisé avec méthodologie documentée et sources citées, dépôts GitHub publics. La preuve remplace le discours.

## Operating Context

- L'utilisateur est en emploi : aucun démarchage, aucun appel à l'action commercial sur le site.
- La Frontière (section /frontiere) est alimentée par un pipeline Python local (collect, curate, publish) qui régénère données JSON et flux RSS.
- SEO travaillé : JSON-LD (WebSite, Person, WebPage, FAQPage), sitemap, robots.txt, llms.txt, Search Console.

## Capabilities and Constraints

- Pages : accueil, projets (avec filtres JS), parcours, recherche, contact, 404, section La Frontière.
- Contraintes confirmées à préserver : ton sobre, français d'abord, HTML/CSS statique sans framework.
- Décisions différées (ne pas relancer sans demande explicite) : version anglaise du site (plan dans personal-branding-ulrich/docs), nouveau portrait, conversion WebP, intégration ICIE live.
- Typographie de rédaction : pas de tiret long dans la prose.

## Brand Commitments

- Ton sobre et factuel, aucune affirmation sans source vérifiable.
- Identité : nom complet, portrait (assets/ulrich-djidonou-portrait.png), favicon SVG, image OG.
- Le look visuel peut évoluer tant que le ton reste sobre (confirmé : pas de gel de la palette actuelle).

## Evidence on Hand

- Dashboard ICIE public et dépôts GitHub (github.com/ulrich-e-r-djidonou).
- Preuves citées sur le site : webinaire JCCM, Matinée RQAP 2024, rapport gouvernemental lié (voir historique git).
- Captures de validation dans personal-branding-ulrich/docs/validation.
- Absences à ne pas fabriquer : pas de témoignages clients, pas de chiffres de performance inventés.

## Product Principles

1. La preuve avant le discours : chaque affirmation publiable est liée à une source ou marquée à valider.
2. Sobriété d'employé en poste : informer, jamais démarcher.
3. Français d'abord, anglais différé jusqu'à demande explicite.
4. Simplicité technique durable : statique, sans dépendance de build, maintenable seul.

## Accessibility & Inclusion

Aucune exigence produit spécifique établie. Standards web de base attendus (contraste, navigation clavier) faute de norme imposée.
