# Questions à répondre pour l'autorité thématique

Document de travail, 29 août 2026. Inventaire de questions à volume de recherche faible ou nul,
formulées comme les pose réellement le public visé (organismes publics, chercheurs, recruteurs,
journalistes économiques). Objectif : couvrir le sujet plutôt que le mot-clé, pour être cité par
les moteurs avec IA.

Ulrich rédige les réponses. Les emplacements sont vides à dessein.

## Mode d'emploi

Une réponse utile fait 60 à 150 mots, commence par la réponse directe en une phrase, puis
développe. Pas de préambule, pas de « il est important de noter ». Une source cliquable quand
la réponse avance un chiffre ou une définition contestable. Le titre visible de la réponse doit
reprendre la question mot pour mot : c'est ce que les moteurs apparient.

Trois destinations possibles :

- **FAQ** : `faq.html`, questions courtes et transversales sur toi et ta pratique.
- **Ressources** : `ressources.html`, questions de méthode qui ont une valeur durable.
- **Projet** : la page du tableau de bord concerné (ICIE, La Frontière, Geoecon Pulse), quand la
  question porte sur l'indicateur lui-même.

Priorité : **P1** à écrire d'abord (questions où tu as un avantage réel et vérifiable), **P2**
ensuite, **P3** si le temps le permet.

## Après rédaction

Quand un bloc est écrit, l'intégration technique consiste à : créer ou étendre la section Q/R sur
la page cible avec des `<h2>` reprenant la question, mettre à jour le JSON-LD `FAQPage` de
`faq.html` (déjà présent) et en ajouter un sur les pages qui n'en ont pas, puis répercuter sur les
versions anglaises dans `/en/`.
